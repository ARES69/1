# 🔍 Диагностика проблем с превью

## Проблема
Превью не отображается после редизайна в стиле OpenCode.

## Решение

Созданы две тестовые страницы для диагностики:

### 1. Простая главная страница (`/`)
- **Файл:** `src/pages/SimpleHome.tsx`
- **Особенности:**
  - Использует только инлайн стили (без Tailwind)
  - Минимальная зависимость от CSS переменных
  - Прямые цвета вместо `var(--color-*)`
  - Простая структура без сложных компонентов

### 2. Тестовая страница (`/test`)
- **Файл:** `src/pages/TestPage.tsx`
- **Особенности:**
  - Максимально простой HTML
  - Только базовые инлайн стили
  - Никаких внешних зависимостей

## Как проверить

### Шаг 1: Откройте тестовую страницу
Перейдите по адресу: `http://localhost:5173/test`

Если эта страница отображается:
- ✅ Базовый рендеринг работает
- ✅ React работает
- ✅ Роутинг работает
- ❌ Проблема в компонентах или CSS

Если эта страница НЕ отображается:
- ❌ Проблема в базовой конфигурации
- Проверьте консоль браузера (F12)
- Проверьте `npm run dev` запущен

### Шаг 2: Откройте простую главную страницу
Перейдите по адресу: `http://localhost:5173/`

Если эта страница отображается:
- ✅ Простая версия работает
- ✅ Проблема в сложных компонентах или CSS переменных
- Можно постепенно добавлять сложные элементы

Если эта страница НЕ отображается:
- ❌ Проблема в базовых компонентах (Header, Footer)
- Проверьте `src/components/Header.tsx`
- Проверьте `src/components/Footer.tsx`

### Шаг 3: Проверьте старую версию
Перейдите по адресу: `http://localhost:5173/home-old`

Если эта страница отображается:
- ✅ Старая версия работает
- ❌ Проблема в новом дизайне
- Нужно проверить CSS переменные и классы

## Возможные проблемы

### 1. CSS переменные не работают
**Симптом:** Страница загружается, но без стилей
**Решение:** Проверьте `src/index.css`, убедитесь что все переменные определены

### 2. Tailwind классы не генерируются
**Симптом:** Страница загружается, но без форматирования
**Решение:** Проверьте `tailwind.config.js` и `postcss.config.js`

### 3. Компоненты не рендерятся
**Симптом:** Белая страница, ошибки в консоли
**Решение:** Проверьте консоль браузера (F12) на ошибки JavaScript

### 4. Роутинг не работает
**Симптом:** 404 ошибка или перенаправление
**Решение:** Проверьте `src/App.tsx` и маршруты

## Диагностика через консоль

Откройте консоль браузера (F12) и выполните:

```javascript
// Проверить, загружен ли React
console.log(React);

// Проверить, загружен ли ReactDOM
console.log(ReactDOM);

// Проверить, есть ли элемент #root
console.log(document.getElementById('root'));

// Проверить, загружен ли CSS
console.log(document.styleSheets);

// Проверить текущий URL
console.log(window.location.href);

// Проверить localStorage
console.log(localStorage.getItem('rsb-theme'));
```

## Проверка CSS переменных

В консоли браузера выполните:

```javascript
// Проверить CSS переменные
const styles = getComputedStyle(document.documentElement);
console.log('Background:', styles.getPropertyValue('--bg'));
console.log('Text:', styles.getPropertyValue('--text'));
console.log('Border:', styles.getPropertyValue('--border'));
console.log('Accent:', styles.getPropertyValue('--accent'));
```

## Проверка темы

```javascript
// Проверить текущую тему
const isDark = document.documentElement.classList.contains('dark');
console.log('Dark mode:', isDark);

// Переключить тему
document.documentElement.classList.toggle('dark');

// Установить светлую тему
document.documentElement.classList.remove('dark');
localStorage.setItem('rsb-theme', 'light');

// Установить тёмную тему
document.documentElement.classList.add('dark');
localStorage.setItem('rsb-theme', 'dark');
```

## Временное решение

Если ничего не помогает, можно временно отключить новый дизайн:

1. В `src/App.tsx` замените:
```tsx
<Route path="/" element={<SimpleHome />} />
```
на:
```tsx
<Route path="/" element={<Home />} />
```

2. Это вернёт старую версию главной страницы
