## 🔒 Как это работает

### Регистрация

1. Пользователь заполняет форму:
   - Имя
   - Email
   - Пароль (минимум 6 символов)

2. Система:
   - Валидирует данные
   - Хеширует пароль
   - Создаёт пользователя в localStorage
   - Начисляет 50 кредитов
   - Автоматически входит в аккаунт
   - Перенаправляет на `/app`

### Вход

1. Пользователь вводит email и пароль
2. Система:
   - Находит пользователя по email
   - Сравнивает хеши паролей
   - Создаёт сессию в localStorage
   - Перенаправляет на `/app`

### Защита маршрутов

```typescript
// src/components/ProtectedRoute.tsx
if (!isLoggedIn()) {
  return <Navigate to="/login" replace />;
}
```

Если пользователь не авторизован и пытается зайти на `/app`, его перенаправит на `/login`.

### Выход

1. Пользователь нажимает "Log out"
2. Система удаляет сессию из localStorage
3. Перенаправляет на `/login`

## 🔧 Использование в коде

### Проверка авторизации

```typescript
import { isLoggedIn, getCurrentUser } from './lib/auth';

if (isLoggedIn()) {
  const user = getCurrentUser();
  console.log('User:', user.email, user.name);
} else {
  // Перенаправить на login
  navigate('/login');
}
```

### Регистрация

```typescript
import { signup } from './lib/auth';

const result = signup('user@example.com', 'password123', 'John Doe');

if (result.success) {
  navigate('/app');
} else {
  setError(result.error);
}
```

### Вход

```typescript
import { login } from './lib/auth';

const result = login('user@example.com', 'password123');

if (result.success) {
  navigate('/app');
} else {
  setError(result.error);
}
```

### Выход

```typescript
import { logout } from './lib/auth';

logout();
navigate('/login');
```

## 🔒 Безопасность

### Что реализовано

✅ **Хеширование паролей**
- Простой хэш для демо
- В production используйте bcrypt на сервере

✅ **Валидация**
- Проверка email формата
- Минимальная длина пароля (6 символов)
- Проверка обязательных полей

✅ **Защита маршрутов**
- ProtectedRoute компонент
- Автоматический редирект на login
- Проверка сессии при каждом запросе

### Ограничения локального хранения

⚠️ **Важно:** localStorage не является безопасным хранилищем для production.

**Рекомендации для production:**
1. Используйте серверную аутентификацию
2. Храните пароли только в хешированном виде на сервере
3. Используйте JWT токены
4. Включите HTTPS
5. Настройте CORS
6. Добавьте rate limiting

## 🐛 Решение проблем

### Проблема: "Invalid email or password"

**Решение:**
- Проверьте правильность email
- Убедитесь, что пароль не менее 6 символов
- Проверьте, что аккаунт зарегистрирован

### Проблема: "Email already registered"

**Решение:**
- Используйте другой email
- Или войдите с существующим аккаунтом

### Проблема: "All fields are required"

**Решение:**
- Заполните все поля формы
- Проверьте, что нет пустых полей

### Проблема: Не перенаправляет на login

**Решение:**
- Очистите localStorage
- Перезагрузите страницу
- Проверьте консоль на ошибки

## 🚀 Production рекомендации

Для production версии рекомендуется:

1. **Серверная аутентификация**
   - Используйте Node.js + Express
   - Или Supabase/Firebase Auth
   - Или Auth0/Clerk

2. **Безопасное хранение**
   - Храните пароли только в хешированном виде
   - Используйте bcrypt или argon2
   - Никогда не храните пароли в plaintext

3. **JWT токены**
   - Access token (короткоживущий)
   - Refresh token (долгоживущий)
   - Храните в httpOnly cookies

4. **HTTPS**
   - Обязательный для production
   - Используйте Let's Encrypt
   - Настройте редирект с HTTP

5. **Rate limiting**
   - Защита от брутфорса
   - Ограничение попыток входа
   - Блокировка после N попыток
